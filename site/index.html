About the Project

About SiteSpy

SiteSpy is a mobile-first construction project records and cost estimation app built with Expo React Native, Firebase, and Firestore. It helps construction teams capture measurements, estimate material costs, and review project history on any device — even in low-connectivity field conditions.

My Contribution

My Contribution

I set up and maintained the Firebase configuration and runtime environment loading for SiteSpy. firebaseConfig.js initialises the Firebase SDK with the correct project credentials at app launch. app.config.js manages the Expo configuration and ensures environment variables are loaded correctly from .env.
