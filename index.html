About the Project

About SiteSpy

SiteSpy is a mobile-first construction project records and cost estimation app built with Expo React Native, Firebase, and Firestore. It helps construction teams capture measurements, estimate material costs, organise site records, and review project history on any device — even in low-connectivity field conditions.

My Contribution

My Contribution

I set up and maintained the Firebase configuration and runtime environment loading for SiteSpy. firebaseConfig.js initialises the Firebase SDK with the correct project credentials at app launch. app.config.js manages the Expo configuration and ensures environment variables are loaded correctly from .env for both development and production builds. .env.example documents the required environment variables so any developer can set up the project without seeing private values.

Reflection

My Reflection

Configuration work is invisible until it breaks, and when it breaks it breaks everything. I learned how to structure environment variable loading so that missing values fail loudly at startup rather than silently at runtime. The biggest lesson was separating what must be secret from what can be public, and documenting that boundary clearly so the team does not accidentally commit private keys.
